每条 Signal 都要回答八个问题：谁产生、看什么标的、什么方向、多可信、为什么、何时有效、能做什么、处于什么生命周期。

Freqtrade 执行底座，双层风控兜底

PulseDesk 不直接连交易所下单。执行走 Freqtrade 官方镜像 + REST/WebSocket + CCXT；AI 只允许生成规则 DSL，Freqtrade 加载固定模板。

Freqtrade

官方 Docker 镜像，回测 / dry-run / live_small，原生止损兜底。

CCXT · REST/WS

订单与控制走 REST，历史交易直读 SQLite，双通道不混用。

StrategyRuleDSL

AI 只产 JSON 规则，经 Validator 校验发布 RulePackage，不生成 Python。

MCP · 只读

外部 AI 客户端可读信号与持仓，v1 不允许下单或关闭风控。

失联即降级：freqtrade_native_guard_only
PulseDesk 失联时禁止升级策略、禁止提高仓位、禁止启动新的 live_small，Freqtrade 仍独立执行基础止损与仓位限制。
