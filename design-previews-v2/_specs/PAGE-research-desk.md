# 页面数据规格 · AI 投研室（PRD 7.2）

> 目标：运行 TradingAgents-style 多 Agent 投研流程。对某个标的进行多 Agent 研究、辩论、风险判断，产出 ResearchReport / TradingSignal / RiskOpinion / StrategyDraft。
> 这是最"叙事流程型"的页面——最能展示交互与动效。

## 页面单一职责
把一次多 Agent 投研过程呈现为**可读的辩论叙事**：从选标的→各观点并陈→多空辩论→风控裁定→最终评级→可发布为 Signal。

## 布局骨架（各风格用自己母题演绎；这页强调"流程/时间线/辩论"的结构）
1. **顶栏**：页面名「AI 投研室 / Research Desk」+ 当前研究标的 **BTC/USDT** + 研究深度选择(快速/标准/**深度** segmented，深度为选中态) + 状态(研究中 6/6 Agent 已发言 · 用时 42s)
2. **研究对象卡**：BTC/USDT · 现价 64,180 · 24h +1.46% · 本次研究触发原因(结构突破信号 #1 请求深度复核)
3. **多 Agent 观点区**（主体 signature）：6 个 Agent 的观点并陈或按流程展开。每个 Agent 卡：Agent 名 + 立场徽标(多/空/中性/风险) + 置信度 + 3-4 句观点摘要 + 关键证据 bullet
4. **多空辩论时间线**（signature 交互）：把多头 vs 空头的往复辩论做成一条时间线/对话流(左右分栏或交替)，体现"辩论"而非"罗列"。至少 4 轮往复
5. **风控观点裁定**：RiskOpinion——是否放行、风险等级、约束条件(独立资金池/仓位上限/止损)
6. **最终评级 + 交易建议**：综合评级(如 偏多 B+ / 置信度 0.74)、方向、目标价/止损/止盈、建议仓位
7. **产出操作**：发布为 Signal / 创建 StrategyDraft / 存为 ResearchReport / 加入观察
